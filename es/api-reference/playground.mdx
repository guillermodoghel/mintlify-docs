# Playground

Cada página de la sección **API Endpoints** tiene un playground: completás los parámetros, mandás el pedido real a la API de Facturear y ves la respuesta sin salir de la documentación. Las páginas se generan desde la especificación OpenAPI, así que muestran los mismos parámetros y respuestas que la API.

## Cómo usarlo

<Steps>
  <Step title="Conseguí tu API Key de testing">
    En [facture.ar](https://www.facture.ar), en el menú lateral, entrá a **Desarrolladores → Claves API** y copiá la key de la tarjeta **Testing** (empieza con `test_sk_`). Ver [API Keys](/es/guides/api-keys).

    <Warning>
      Usá la key de testing. Con la de producción (`prod_sk_`), el playground emite comprobantes reales ante ARCA.
    </Warning>
  </Step>

  <Step title="Elegí un endpoint">
    Algunos para empezar:

    - `GET /cuits`: tus CUITs, con su id en Facturear
    - `POST /invoices`: emitir una factura (o varias, mandando un array)
    - `GET /invoices/batches/{batchId}`: el resultado de la emisión, con el CAE
    - `GET /invoices`: listar y buscar facturas. Para buscar, usá los parámetros `search`, `receptor`, `cuit`, `tipo`, `comprobante` y `status`
    - `GET /invoices/{invoiceId}/pdf`: el PDF de una factura
  </Step>

  <Step title="Mandá el pedido">
    Pegá tu key en el campo `x-api-key`, completá los parámetros y el body, y tocá **Send**. Debajo ves la respuesta y el ejemplo de código en cURL, JavaScript, Python y PHP para copiar.
  </Step>
</Steps>
