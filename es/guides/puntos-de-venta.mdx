# Puntos de venta en Facturear

Los **puntos de venta** son identificadores numéricos que ARCA usa para organizar la facturación electrónica. Cada factura lleva el número de punto de venta más el número correlativo (ej: 0001-00000001). Esta guía explica cómo gestionarlos en Facturear.

---

## ¿Qué es un punto de venta?

Un punto de venta (PDV) es un número del 1 al 9999 que:

- Identifica el origen de la facturación (física o electrónica)
- Reinicia el correlativo de numeración por cada número de PDV
- Puede representar una sucursal, un sistema diferente, un tipo de cliente, etc.

Para empezar a facturar con Facturear alcanza con uno, y lo dejamos listo nosotros al conectar tu CUIT.

---

## El punto de venta al conectar tu CUIT

No tenés que darlo de alta vos. Cuando [conectás tu CUIT](/es/getting-started/index), nuestro agente de trámites entra a ARCA y deja listo un punto de venta Web Services. Si ya tenías uno, usamos ese. Queda como punto de venta por defecto del CUIT.

---

## Agregar otro punto de venta

Si querés usar más de un punto de venta (por sucursal, por canal, etc.), el nuevo se da de alta en ARCA:

<Steps>
  Entrá a **arca.gob.ar** con tu clave fiscal → **Administración de puntos de venta y domicilios**

  Elegí el CUIT y dá de **alta** un nuevo punto de venta con un número libre

  En el sistema, elegí uno de **Web Services**: "Factura Electrónica - Monotributo - Web Services" si sos monotributista, o "RECE para aplicativo y web services" si sos responsable inscripto o exento

  Confirmá el alta

  En Facturear, andá a **CUITs** → tu CUIT → **Puntos de Venta** y tocá **Actualizar** para traerlo
</Steps>

---

## Tipos de puntos de venta

Facturear emite por el web service de factura electrónica de ARCA, así que el punto de venta tiene que ser de un sistema **Web Services**. Los otros no sirven para emitir con Facturear:

| Sistema en ARCA | ¿Sirve con Facturear? |
|---|---|
| Factura Electrónica - Monotributo - Web Services | Sí |
| RECE para aplicativo y web services | Sí |
| Comprobantes en línea (factura desde la web de ARCA) | No |
| Controlador fiscal | No |
| CAEA | No, Facturear todavía no lo soporta (ver [CAEA](/es/guides/factura-caea)) |

## Listar puntos de venta en Facturear

Facturear guarda los puntos de venta que ARCA informa para cada CUIT. Se consultan con el **id del CUIT en Facturear** (lo obtenés con `GET https://www.facture.ar/api/cuits`).

### GET /api/cuits/{id}/pos

```bash
curl https://www.facture.ar/api/cuits/cmg0a1b2c0000abc/pos \
  -H "x-api-key: tu_api_key"
```

### Respuesta

Devuelve la última lista obtenida de ARCA, cuándo se actualizó, el punto de venta por defecto del CUIT y, en `lastInvoices`, la última factura emitida con Facturear en cada punto de venta (en el entorno de tu clave: producción o testing):

```json
{
  "pos": {
    "pos": {
      "ResultGet": {
        "PtoVenta": [
          { "Nro": 1, "EmisionTipo": "CAE", "Bloqueado": "N", "FchBaja": "NULL" },
          { "Nro": 2, "EmisionTipo": "CAE", "Bloqueado": "N", "FchBaja": "NULL" }
        ]
      }
    },
    "posLastUpdated": "2026-09-15T13:30:00.000Z",
    "default_pos": 1
  },
  "lastInvoices": [
    {
      "ptoVta": 1,
      "id": "cmg1a2b3e0002xyz",
      "invoiceType": 11,
      "voucherNumber": 128,
      "createdAt": "2026-09-29T18:04:11.000Z"
    }
  ]
}
```

### Actualizar la lista desde ARCA

Si diste de alta un punto de venta nuevo en ARCA, pedile a Facturear que vuelva a consultarlos:

### POST /api/cuits/{id}/pos

```bash
curl -X POST https://www.facture.ar/api/cuits/cmg0a1b2c0000abc/pos \
  -H "x-api-key: tu_api_key"
```

```json
{
  "message": "Points of sale fetched and updated successfully",
  "pos": {
    "ResultGet": {
      "PtoVenta": [
        { "Nro": 1, "EmisionTipo": "CAE", "Bloqueado": "N", "FchBaja": "NULL" }
      ]
    }
  }
}
```

La consulta se hace siempre contra ARCA **producción**. Si ARCA no devuelve ningún punto de venta, la respuesta es `400`: primero tenés que dar de alta uno en ARCA.

### Último comprobante en ARCA

`lastInvoices` solo mira lo que emitiste con Facturear. Para ver el último número que ARCA tiene autorizado en cada punto de venta y tipo de comprobante (incluido lo que emitiste por fuera de Facturear), usá:

```bash
curl https://www.facture.ar/api/cuits/cmg0a1b2c0000abc/pos/last-vouchers \
  -H "x-api-key: tu_api_key"
```

```json
{
  "lastVouchers": [
    { "ptoVta": 1, "invoiceType": 11, "voucherNumber": 128, "date": "2026-09-29", "invoiceId": "cmg1a2b3e0002xyz" }
  ]
}
```

`date` es la fecha del comprobante en ARCA (`AAAA-MM-DD`) e `invoiceId` es la factura en Facturear, o `null` si no se emitió desde acá. Consulta a ARCA, así que tarda unos segundos. La primera vez que se cargan, el primero de la lista queda como punto de venta por defecto; lo podés cambiar con `POST /api/cuits/{id}/default-pos` (ver [Configurar defaults por CUIT](/es/guides/configurar-defaults-cuit)).

Desde el dashboard, lo mismo está en **CUITs** → tu CUIT → **Puntos de Venta**, con el botón **Actualizar**. Ahí también cambiás el punto de venta por defecto con **Establecer como predeterminado**.

## Número de comprobante

<Info>
  Facturear maneja automáticamente el incremento del número de comprobante. No necesitás controlar la numeración manualmente; el sistema consulta a ARCA y asigna el número correcto. El número asignado vuelve en `voucherNumber`, en el resultado del lote y en `GET /api/invoices`.
</Info>

## Uso de múltiples puntos de venta

Estrategias comunes para usar múltiples PDV:

| Estrategia | PDV 1 | PDV 2 |
|---|---|---|
| Por tipo de cliente | Facturas A (empresa) | Facturas B (consumidor) |
| Por canal | Facturación web | Facturación por API |
| Por sucursal | Sucursal Buenos Aires | Sucursal Córdoba |
| Por sistema | Sistema propio | Facturear |

---

## Baja de un punto de venta

Si necesitás dar de baja un punto de venta:

1. Tramitá la baja en **arca.gob.ar → Administración de puntos de venta y domicilios**
2. Una vez dado de baja en ARCA, ese PDV no podrá usarse para emitir más facturas
3. Los comprobantes emitidos previamente desde ese PDV siguen siendo válidos

## Preguntas frecuentes

<AccordionGroup>
  <Accordion title="¿Puedo usar el mismo punto de venta para distintos tipos de factura (A, B, C)?">
    Sí. Un punto de venta puede usarse para emitir distintos tipos de comprobante. La numeración es independiente por tipo: el último número de la Factura A es distinto al último número de la Factura B, aunque usen el mismo punto de venta.
  </Accordion>
  <Accordion title="¿Qué pasa si el punto de venta no está dado de alta en ARCA?">
    ARCA rechaza la solicitud de facturación: el error indica que el punto de venta no existe o no está habilitado para el CUIT. Dalo de alta en ARCA como Web Services (ver [Agregar otro punto de venta](#agregar-otro-punto-de-venta)) y tocá **Actualizar** en Facturear.
  </Accordion>
</AccordionGroup>
