# API de parámetros ARCA

ARCA mantiene tablas de referencia que se usan al emitir facturas: tipos de comprobante, alícuotas de IVA, monedas, tipos de documento, condiciones frente al IVA, tributos y más.

Facturear expone los principales a través de su API para que no tengas que hardcodearlos en tu sistema.

---

## ¿Por qué usar la API de parámetros?

- Los parámetros de ARCA **se actualizan periódicamente** (nuevos tipos de comprobante, cambios de alícuotas, nuevas condiciones frente al IVA, etc.)
- Si hardcodeás los valores, tu sistema puede quedar desactualizado
- La API de Facturear devuelve los valores que informa ARCA

---

## Endpoint disponible

Todos los parámetros se consultan con un único endpoint, pasando el nombre del método de ARCA en la URL:

```bash
GET https://www.facture.ar/api/arca/{name}
```

```bash
curl https://www.facture.ar/api/arca/FEPARAMGETTIPOSIVA \
  -H "x-api-key: tu_api_key"
```

Valores soportados para `{name}`:

| `name` | Qué devuelve |
|---|---|
| `FEPARAMGETTIPOSCBTE` | Tipos de comprobante |
| `FEPARAMGETTIPOSIVA` | Alícuotas de IVA |
| `FEPARAMGETTIPOSDOC` | Tipos de documento del receptor |
| `FEPARAMGETTIPOSCONCEPTO` | Conceptos (productos, servicios, ambos) |
| `FEPARAMGETTIPOSMONEDAS` | Monedas |
| `FEPARAMGETCOTIZACION` | Cotización de una moneda (requiere `?codId=`) |
| `FEPARAMGETTIPOSTRIBUTOS` | Tipos de tributo |
| `FEPARAMGETCONDICIONIVARECEPTOR` | Condiciones frente al IVA del receptor (acepta `?claseCmp=`) |

Cualquier otro nombre responde `400` con la lista de valores soportados. Si ARCA no está disponible para devolver el parámetro, la respuesta es `503`.

<Note>
  La respuesta es la de ARCA tal cual: un objeto con `ResultGet`, que adentro trae la lista (por ejemplo `ResultGet.IvaTipo`). Facturear guarda en caché los parámetros por 30 días y la cotización hasta el fin del día.
</Note>

## Parámetros más usados

### Tipos de comprobante

```bash
GET https://www.facture.ar/api/arca/FEPARAMGETTIPOSCBTE
```

```json
{
  "ResultGet": {
    "CbteTipo": [
      { "Id": 1, "Desc": "Factura A", "FchDesde": "20100917", "FchHasta": "NULL" },
      { "Id": 6, "Desc": "Factura B", "FchDesde": "20100917", "FchHasta": "NULL" },
      { "Id": 11, "Desc": "Factura C", "FchDesde": "20110330", "FchHasta": "NULL" }
    ]
  }
}
```

### Alícuotas de IVA

```bash
GET https://www.facture.ar/api/arca/FEPARAMGETTIPOSIVA
```

```json
{
  "ResultGet": {
    "IvaTipo": [
      { "Id": 3, "Desc": "0%", "FchDesde": "20090220", "FchHasta": "NULL" },
      { "Id": 4, "Desc": "10.5%", "FchDesde": "20090220", "FchHasta": "NULL" },
      { "Id": 5, "Desc": "21%", "FchDesde": "20090220", "FchHasta": "NULL" },
      { "Id": 6, "Desc": "27%", "FchDesde": "20090220", "FchHasta": "NULL" }
    ]
  }
}
```

### Monedas y cotización

```bash
GET https://www.facture.ar/api/arca/FEPARAMGETTIPOSMONEDAS
```

La lista viene en `ResultGet.Moneda` (`{ Id, Desc, ... }`, por ejemplo `PES` o `DOL`). Para la cotización de una moneda, pasá su `Id` en `codId`:

```bash
GET https://www.facture.ar/api/arca/FEPARAMGETCOTIZACION?codId=DOL
```

```json
{
  "ResultGet": { "MonId": "DOL", "MonCotiz": 1350.5, "FchCotiz": "20260928" }
}
```

### Tipos de documento

```bash
GET https://www.facture.ar/api/arca/FEPARAMGETTIPOSDOC
```

Tipos de documento para identificar al receptor (DNI, CUIT, pasaporte, etc.), en `ResultGet.DocTipo`.

### Condición frente al IVA del receptor

```bash
GET https://www.facture.ar/api/arca/FEPARAMGETCONDICIONIVARECEPTOR?claseCmp=A
```

Cada condición viene en `ResultGet.CondicionIvaReceptor` con `Id`, `Desc` y `Cmp_Clase`. Ver [Condición frente al IVA del receptor](/es/guides/condicion-iva-receptor).

## Ejemplo de uso en una integración

```javascript
// Al inicializar tu app, cacheá los parámetros
const API = 'https://www.facture.ar/api'

async function obtenerParametro(name) {
  const res = await fetch(`${API}/arca/${name}`, {
    headers: { 'x-api-key': API_KEY }
  })
  if (!res.ok) throw new Error(`No se pudo obtener ${name}: ${res.status}`)
  const { ResultGet } = await res.json()
  return ResultGet
}

async function cargarParametrosARCA() {
  const [comprobantes, alicuotas, monedas, documentos] = await Promise.all([
    obtenerParametro('FEPARAMGETTIPOSCBTE'),
    obtenerParametro('FEPARAMGETTIPOSIVA'),
    obtenerParametro('FEPARAMGETTIPOSMONEDAS'),
    obtenerParametro('FEPARAMGETTIPOSDOC')
  ])

  // Guardá en caché (Redis, memoria, etc.)
  await cache.set('arca:tiposComprobante', comprobantes.CbteTipo, 86400) // 24hs TTL
  await cache.set('arca:alicuotas', alicuotas.IvaTipo, 86400)
  await cache.set('arca:monedas', monedas.Moneda, 86400)
  await cache.set('arca:tiposDocumento', documentos.DocTipo, 86400)
}
```
