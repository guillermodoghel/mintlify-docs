# Buscar y consultar facturas emitidas

La API de Facturear incluye endpoints para **consultar el historial de facturas** emitidas. Podés filtrar por CUIT emisor, receptor, tipo de comprobante, número o estado, y obtener los detalles completos incluyendo la respuesta de ARCA con el CAE y el PDF.

---

## Listar facturas

### GET /api/invoices

Lista las facturas de tu cuenta, de la más nueva a la más vieja. Con la key de producción ves las facturas de producción; con la de testing, las de homologación.

```bash
curl "https://www.facture.ar/api/invoices" \
  -H "x-api-key: tu_api_key"
```

### Con filtros

```bash
curl "https://www.facture.ar/api/invoices?cuit=20123456789&tipo=6&status=success&limit=50" \
  -H "x-api-key: tu_api_key"
```

---

## Parámetros de búsqueda disponibles

| Parámetro | Tipo | Descripción | Ejemplo |
|---|---|---|---|
| `cuit` | string | CUIT emisor (o parte de él) | `20123456789` |
| `receptor` | string | Documento del receptor (CUIT, CUIL o DNI, con o sin guiones) o parte de su nombre | `20-12345678-9`, `Acme` |
| `tipo` | integer | Código de ARCA del tipo de comprobante | `1` (A), `6` (B), `11` (C) |
| `comprobante` | string | Número de comprobante (se toman solo los dígitos) | `145` |
| `status` | string | Estado de la factura | `success`, `error`, `processing` |
| `search` | string | Busca en CUIT emisor, número de comprobante, código de tipo de comprobante y descripción | `consultoría` |
| `page` | integer | Página (desde `1`) | `1` |
| `limit` | integer | Resultados por página (default `10`, máx. `100`) | `50` |

Todos los filtros se combinan: si mandás varios, la factura tiene que cumplir con todos.

### Buscar por receptor

`receptor` encuentra las facturas emitidas a un cliente. Si le pasás un número de documento, busca por el `DocNro` exacto de la factura: `20-12345678-9`, `20.123.456.789` y `20123456789` dan lo mismo. Si le pasás texto, busca por el nombre del cliente (`clientName`) sin distinguir mayúsculas, así que solo encuentra las facturas que emitiste con ese campo.

```bash
curl "https://www.facture.ar/api/invoices?receptor=20-12345678-9&tipo=6" \
  -H "x-api-key: tu_api_key"
```

<Note>
  El listado no tiene filtro por fecha ni por punto de venta. Para un período, recorré las páginas y filtrá por `createdAt` (la lista ya viene ordenada por fecha de creación), y por `ptoVta` si lo necesitás.
</Note>

## Consultar una factura específica

### GET /api/invoices/{id}

```bash
curl "https://www.facture.ar/api/invoices/cmg1a2b3e0002xyz" \
  -H "x-api-key: tu_api_key"
```

Devuelve la factura con los mismos campos que el listado, o `404` si no existe o no es tuya.

O por número de comprobante:

```bash
curl "https://www.facture.ar/api/invoices?cuit=20123456789&tipo=6&comprobante=145" \
  -H "x-api-key: tu_api_key"
```

Si emitís con varios puntos de venta, el mismo número puede repetirse: revisá `ptoVta` en el resultado.

## Obtener el PDF de una factura

```bash
curl "https://www.facture.ar/api/invoices/cmg1a2b3e0002xyz/pdf?download=true" \
  -H "x-api-key: tu_api_key" \
  --output factura.pdf
```

O como URL de descarga (sin `download=true`):

```bash
curl "https://www.facture.ar/api/invoices/cmg1a2b3e0002xyz/pdf" \
  -H "x-api-key: tu_api_key"
```

```json
{
  "download_url": "https://...",
  "invoice_id": "cmg1a2b3e0002xyz",
  "invoice_number": "0001-00000145",
  "environment": "production"
}
```

También podés obtener la respuesta de ARCA en XML con `GET /api/invoices/{id}/xml`. Ver [Descarga masiva de PDFs](/es/guides/descarga-pdf-masiva).

## Filtrar por estado

Las facturas pueden tener estos estados:

| Estado | Descripción |
|---|---|
| `success` | Factura emitida exitosamente con CAE |
| `error` | Hubo un error al emitir (por ejemplo, ARCA la rechazó). El motivo está en `errorMessage` |
| `processing` | Se está pidiendo el CAE a ARCA |

Las facturas en error también se listan con `GET /api/invoices/pending` (misma paginación), y `GET /api/invoices/stats` devuelve el resumen: `totalInvoices`, `successInvoices`, `errorInvoices`, `totalAmount` (de las exitosas) y `pendingJobs` (en cola).

## Exportar facturas a CSV

Facturear no tiene un endpoint de exportación a CSV. Podés armarlo recorriendo `GET /api/invoices` página por página y escribiendo los campos que necesites (`voucherNumber`, `ptoVta`, `invoiceType`, `amount`, `createdAt`, etc.).

---

## Ejemplo: buscar las facturas de un mes

```javascript
async function facturasDelMes(miCuit, mes, anio) {
  const desde = new Date(anio, mes - 1, 1);
  const hasta = new Date(anio, mes, 1);
  const resultado = [];

  for (let page = 1; ; page++) {
    const params = new URLSearchParams({ cuit: miCuit, status: 'success', page, limit: 100 });
    const response = await fetch(`https://www.facture.ar/api/invoices?${params}`, {
      headers: { 'x-api-key': apiKey }
    });
    const { invoices, pagination } = await response.json();

    for (const factura of invoices) {
      const creada = new Date(factura.createdAt);
      if (creada >= desde && creada < hasta) resultado.push(factura);
    }

    const ultima = invoices[invoices.length - 1];
    if (!pagination.hasNextPage || (ultima && new Date(ultima.createdAt) < desde)) break;
  }

  console.log(`Facturas del mes: ${resultado.length}`);
  return resultado;
}
```
